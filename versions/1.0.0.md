## 🎉 1.0.0 — First tracked release

This is the first release recorded in the changelog. From here on, every deploy
to development, staging, and production lands its own entry on this page.

### ✨ What's new

- **What's New page** — this page. Every release now ships with notes written by
  the developer who built it, reviewed in the pull request alongside the code.
- **Unread indicator** — a dot appears next to "What's New" in the sidebar when
  there's something you haven't read. It clears once you open this page and
  comes back on the next release.

### 🔧 Under the hood

- Release notes live in the repo under `versions/`, one markdown file per
  version, and are inserted into each environment's database as it receives the
  release.
- CI now blocks any pull request into `develop`, `staging`, or `main` that
  bumps the version without writing notes — or writes notes without bumping the
  version.
