### 🔀 See at a glance which events are in GoodShuffle

**Quotes & Bookings →** every event that is linked to GoodShuffle now carries the
GoodShuffle logo beside its name in the table. Hover it and it tells you what it
means.

**Quotes & Bookings → Filters → In GoodShuffle.** A new dropdown with three
choices: **Any** leaves the list alone, **Yes** shows only linked events, and
**No** shows only the ones still waiting to be linked — useful for finding what
has slipped through.

An event with an empty GoodShuffle field counts as **not** linked, so the "No"
list is the real list of work left to do.
