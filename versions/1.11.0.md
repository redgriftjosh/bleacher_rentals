### 🕘 Pickup and dropoff time: Exact, Flexible, or Any Time

**Work Trackers → open a tracker → Pickup/Dropoff Time.** Pickup and dropoff
time used to be a free-text box, so it sorted and displayed however it was
typed. It's now a picker with three options: **Exact** (one time), **Flexible**
(a from/to window), or **Any Time** — every tracker that never had a time set
now shows "Any Time" instead of blank. Trips within the same day now sort by
their actual pickup time on the weekly trip list, the driver PDF, and the
admin's all-work-trackers table.

![Pickup Time field showing Exact, Flexible, and Any Time options, with Flexible selected and a from/to range of 8:00 AM to 9:00 AM](/changelog/1.11.0-pickup-time.png)

### 🚚 Work tracker type is now a color-coded picker

**Work Trackers → open a tracker.** Type used to be a free-text field. It's
now a dropdown with three fixed options — **Trip**, **Repair/Maintenance**, and
**Site Visit/Cleaning/Other** — each with its own color and icon. Only Trip
shows separate Pickup and Dropoff sections and the route map; the other two
types collapse to one generic set of fields (still Setup/Teardown Required and
all), and the Bill of Lading PDF follows the same layout.

![The Type dropdown open, showing Trip, Repair / Maintenance, and Site Visit / Cleaning / Other, each with its own icon](/changelog/1.11.0-worktracker-types.png)

**Configuration → Work Tracker Types** (admin only) now only edits which
QuickBooks account each of the 3 types posts to. The old page that let anyone
add, rename, or delete types is gone.

Until the next driver mobile app release, all work trackers will still appear to
drivers as if they are Trips, even when they are a different type in the admin
app.

### 🕐 Drive Time and Mileage on the weekly trip list

**Work Trackers → a driver's week.** Two new columns, on the page and in the
downloaded PDF, showing each trip's drive time (e.g. "2.4 hrs") and distance
(e.g. "21.4 mi (34.4 km)"), with a total on the SubTotal row.

![The driver PDF showing new Time and Drive Time columns, with Drive Time and Milage highlighted](/changelog/1.11.0-worktracker-milage.png)
