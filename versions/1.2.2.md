### 🖱️ Work trackers are easier to move on the Dashboard

On the **Dashboard schedule grid**, a small work tracker displayed over an event
can now be picked up and moved reliably. The cursor no longer flickers between
the trip and the event, and the event no longer interrupts the drag.

This makes it easier for account managers to reschedule driver work without
opening each work tracker first.
