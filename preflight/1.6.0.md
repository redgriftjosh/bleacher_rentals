# Preflight — 1.6.0

PR: #360
Status: passed
Signed: 2026-08-27 against 192f396

French quotes, driver-reported bleacher swaps, auto-populated work tracker POCs,
and a dashboard shortcut for creating work trackers.

## New in this release

- [x] Companies & Contacts → open a contact → Edit → set **Quote Language** to
      French → Save → reopen it. The field still says French.
- [x] Send that contact a quote and open the client link. The quote page, the
      contract tab and the pay tab are all French, and money reads `1 000,00 $`.
- [x] Download the PDF from that quote. It is French throughout, the accents
      render, and no French label overflows its column or wraps badly.
- [x] Create a contact from inside the quote builder and set its language there.
      The field is on that form too.
- [x] Work Trackers → open a trip → **Details** → click the locate button beside
      **Pickup POC**. It fills from the booked event or neighbouring trip, and
      the phone number arrives with the name.
- [x] Do the same on a trip whose neighbour has a typed-in POC with no contact
      behind it. It refuses and tells you to create the contact first.
- [x] Dashboard → ⌘+click an empty cell (Ctrl+click on Windows). A new work
      tracker opens for that bleacher and date. Try a bleacher that is not
      yours: refused.
- [x] Have a driver confirm a different bleacher than the one assigned. You get
      the notification, and it names both bleachers and the reason.

## Could have broken

- [x] Send an **English** quote and read it end to end. It must look exactly as
      it did before this release — this is the regression that would hurt most.
- [x] Companies & Contacts → create and edit a **company**. The merge rewrote
      these forms; check validation, spacing and where errors appear.
- [x] Work Trackers → check the driver list shows the drivers you expect. It now
      follows zones rather than direct assignment.

## Not testing

- **Who can do what** (viewer read-only, developer locked out, AM zone scope) —
  `contactsAccess.viewer.spec.ts`, `roleAccess.developer.spec.ts` and
  `driverScope.am.spec.ts` drive the real UI and read Postgres back.
- **The client's language toggle** — `quoteFrench.public.spec.ts` covers the
  globe switching the page, the choice surviving a reload, and the contact
  record staying untouched. Clicking it again by hand would add nothing.
- **The PDF respecting `?lang=`** — `api/quotes/[id]/pdf/route.test.tsx`, added
  for this release. Covers French, explicit English, and falling back to the
  contact's language for a missing or unknown value.
- **Stripe checkout opening in French** — `api/payments/create-checkout/route.test.ts`,
  added for this release. Asserts `locale: "fr-CA"` for a French quote and
  `"auto"` otherwise.
- **The bleacher swap notification rules** — `supabase/tests/actual_bleacher.test.sql`,
  seven scenarios covering who is notified and who is not. Better than clicking:
  the driver's side lives in the mobile app, a separate codebase.
- **Quote language reaching the database** — `createContact.test.ts` and
  `updateContact.test.ts`.
- **Money and date formatting** — `quoteFormat.test.ts`, both languages,
  negatives, both currencies.
- **English text sneaking onto a quote** — `noHardcodedText.test.ts` fails the
  build if a string bypasses the dictionary.
- **`TextField` label accessibility** — `<label>` has no `htmlFor`, so screen
  readers do not announce these fields. A real defect, found during this
  release, but it predates this PR and clicking would not reveal it. Worth its
  own fix.
