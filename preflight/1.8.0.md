# Preflight — 1.8.0

PR: #366
Status: planned

**This is a big release.** Five features across eighty files, eleven commits and
four migrations: drivers filing tickets, a driver satisfaction survey, instant
create and autosave on the roadmap, driver document previews, and a rebuilt
ConfirmDialog used all over the app.

Twelve items is the most that can be checked by hand in one sitting, and this
release needs every one of them. If a release this size becomes normal, splitting
it in two would be safer than trusting a longer list.

## New in this release

- [x] From the driver mobile app, file a ticket. It appears in **Roadmap →
      Backlog**, and the card shows who submitted it.
- [x] As that same driver, edit the ticket you just filed — allowed. Then try to
      open or edit someone else's roadmap item — refused.
- [x] **Driver Satisfaction** appears in the sidebar for an admin, and the page
      loads with the stat tiles, the trend chart and the responses table filled.
- [x] Change the period control and the score filter — the tiles, the chart and
      the table all move together and agree with each other.
- [x] As a **driver**, answer the survey in the mobile app, then look for
      `/driver-satisfaction` in the web app: no sidebar entry, and the URL is
      refused if typed directly.
- [x] As an **account manager**, open Driver Satisfaction — you can read every
      response but cannot edit a survey, a question or a response.
- [x] **Roadmap →** create a feature and a task. Each appears immediately,
      before you have finished filling it in.
- [x] Edit a roadmap record and stop typing. It saves on its own and the save
      indicator says so. Reload the page: your edit is there.
- [x] Edit a roadmap record, then go offline mid-edit. The indicator shows the
      save did not land, and nothing is silently lost.
- [x] **Team →** open a driver **→ Driver tab**. Preview a document without
      downloading it, and set an expiry date. Reopen the driver: the date is
      still there and the document still previews.

## Could have broken

- [ ] **ConfirmDialog was rebuilt.** Find three places that use it outside the
      roadmap — deleting a contact, deleting a work tracker, deactivating a team
      member — and check each still opens, cancels, confirms, and closes on Esc.
- [ ] **The sidebar changed.** Log in as admin, account manager, developer and
      viewer in turn. Each sees the entries they saw before, plus Driver
      Satisfaction for all four.

## Not testing

- **Permissions for the satisfaction page** — `driverSatisfactionAccess.test.ts`
  covers all five roles, including that being a driver never removes a page an
  office role grants.
- **Who may read which survey response** — `driver_satisfaction.test.sql` at the
  database level, where row-level security actually decides.
- **The satisfaction figures themselves** — `aggregate`, `scoreTrend` (daily,
  weekly and the general case), `scoreFilter`, `period` and `formatScore` all
  have their own tests. Arithmetic is the last thing worth checking by hand.
- **Autosave mechanics** — `AutosaveEngine.test.ts` and
  `roadmapAutosave.admin.spec.ts`. The manual items above are about what you
  _see_ while it happens, which no test judges.
- **Driver documents logic** — `driverDocuments.test.ts`,
  `DriverDocumentCard.test.tsx` and `driver-documents.admin.spec.ts`.
- **ConfirmDialog itself** — `ConfirmDialog.test.tsx`. The manual item is about
  the places that _use_ it, which the test cannot reach.
- **The version bump** — `/changelog 366` has not run yet. This file assumes
  1.8.0; if it picks another number, this file must be renamed to match or the
  CI gate will not find it.

## Permissions changed for this release

Two entries in `permissionPageData.ts`, which renders `/permissions` for every
authenticated user:

- **Backlog / Tickets → driver** was `none` and said drivers only use the mobile
  app. The migration now grants them insert and update on `RoadmapTasks`, so the
  matrix contradicted the code. It now says they may file a ticket and edit their
  own for a short window, and nothing else.
- **Driver Satisfaction** is new: admin full, developer manages surveys and
  questions, account manager and viewer read-only, driver answers in the mobile
  app and sees only their own responses.
