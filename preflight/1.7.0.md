# Preflight — 1.7.0

PR: #363
Status: passed
Signed: 2026-08-27 against 55865dc

A GoodShuffle indicator and filter on Quotes & Bookings. Small release: two
commits, both read-only additions to one page.

## New in this release

- [x] Quotes & Bookings → the GoodShuffle logo appears beside the name of events
      that are linked, and not on the others. Hover it: the tooltip appears
      immediately, with no delay, and says what it means.
- [x] Filters → **In GoodShuffle → Yes**. Only events showing the logo remain.
- [x] Filters → **In GoodShuffle → No**. Only events without it remain, and the
      two counts add up to the unfiltered total.
- [x] Set the filter, then press **Clear Filters**. The dropdown returns to
      **Any** and every event comes back.

## Could have broken

- [x] Quotes & Bookings with no filters — the list loads and shows what it did
      before. Its query gained a column; if that were wrong the page would be
      empty or error.
- [x] Open the **Scorecard**. Its numbers load as usual. Its query gained the
      same column, and it is the one place in this diff outside Quotes &
      Bookings.

## Not testing

- **The filter logic itself, including blank and whitespace-only URLs** —
  `filterEvents.test.ts`, five tests, added with this feature. It also covers
  combining the filter with Status.
- **Both queries still selecting `goodshuffle_url`** — `expect<T>()` fails the
  build if either drops it. That is what caught the Scorecard query in the first
  place.
- **`goodshuffle_url` being available offline** — already in `AppSchema.ts`, so
  PowerSync syncs it; checked rather than assumed.
- **The badge component on its own** — an image and a tooltip, no logic. Whether
  it looks right at 14px beside the text is the first item above, which is a
  judgement only you can make.
- **Permissions** — nothing changed. `/quotes-bookings` is reachable by admin,
  account manager and viewer, and this release only adds ways to _read_ what is
  already on the page. No entry in `permissionPageData.ts` needed.
